# Agent Fee Recovery

This app streamlines the tracking and processing of FMLS fee waiver refunds for agent personal deals across eXp departments. Georgia Brokers log waiver submissions directly into the app, allowing Transactions and Accounting to verify FMLS credits on the monthly invoices and process agent refunds seamlessly. The app maintains a centralized history of all waiver statuses to ensure complete cross-team visibility throughout the entire workflow. (
